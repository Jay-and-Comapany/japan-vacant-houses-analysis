[![Commercial Portal](https://img.shields.io/badge/Data_Portal-Jay_Portal-emerald.svg)](https://jay-portal.pages.dev/catalog/#akiya)

**日本の空き家統計（1958〜2023年・65年間推移）および令和5年最新市区町村別空き家率・放置空き家率分析CLIツール**

総務省統計局「住宅・土地統計調査」（昭和33年〜令和5年）の公的統計一次データに基づき、日本全国・47都道府県・1,037市区町村の空き家構造を高速にスクリーニング・分析できるオープンソースツールです。標準ライブラリのみで動作し、外部依存パッケージは一切不要です。

---

## 1. 背景と課題

日本の空き家数は、1973年の172万戸（空き家率5.5%）から、2023年最新調査において**900万1,600戸（空き家率13.84%）**へと50年間で約5.2倍に急増しました。

特に深刻なのは、賃貸・売却用や別荘等を除いた、利活用目的のない**「その他の空き家（放置空き家）」が385万6,000戸（総住宅数の5.93%）**に達している点です。

本リポジトリは、自治体政策、空き家再生ビジネス、不動産投資、データジャーナリズム、地域分析に従事する技術者・アナリスト向けに、即座に集計・スクリーニングできる分析環境を提供します。

---

## 2. クイックスタート

Python 3.8以上がインストールされていれば、クローン後すぐに実行できます。

```bash
git clone https://github.com/Jay-and-Comapany/japan-vacant-houses-analysis.git
cd japan-vacant-houses-analysis

# 1. 令和5年 市区町村別 空き家率ランキング（上位10件）
python3 akiya_growth_and_vacancy_analyst.py --mode ranking --limit 10

# 2. 放置空き家率（その他の空き家）ランキング
python3 akiya_growth_and_vacancy_analyst.py --mode ranking --sort other --limit 10

# 3. 65年間（1958〜2023年）の全国・都道府県別 CAGR（年平均成長率）推移
python3 akiya_growth_and_vacancy_analyst.py --mode timeseries --limit 15

# 4. JSON形式で出力（パイプライン連携用）
python3 akiya_growth_and_vacancy_analyst.py --mode ranking --format json --limit 5
```

## 3. 分析実行例とハイライト（実測値）

### (1) 65年間の空き家推移・CAGR分析（`--mode timeseries`）

```text
=== 日本全国・都道府県別 空き家65年間推移・CAGR成長分析 (1958〜2023年) ===

地域 / 都道府県    | 指標           |      1958/初期 |       2023最新 |       倍率 |       全成長率 |    CAGR(年平均)
------------------------------------------------------------------------------------
全国           | vacant_total |  1,720,300.0 |  9,001,600.0 |    5.23x |    +423.3% |    +3.37%/yr
北海道          | vacant_total |     21,000.0 |    451,900.0 |   21.52x |   +2051.9% |    +4.83%/yr
青森県          | vacant_total |      2,000.0 |     98,800.0 |    49.4x |   +4840.0% |    +6.18%/yr
岩手県          | vacant_total |      3,200.0 |    100,400.0 |   31.38x |   +3037.5% |    +5.44%/yr
宮城県          | vacant_total |      3,400.0 |    140,300.0 |   41.26x |   +4026.5% |    +5.89%/yr
```

- 全国総数は50年間で **5.23倍（+423.3%）**、年平均 **+3.37%** で一貫して増加。
- 地方圏（青森県・宮城県等）では、高度経済成長期の住宅ストック急増から過疎化・高齢化に伴い、昭和33年比で **40倍〜50倍** に達している現実が浮き彫りになります。
